# PjBL2-Tabela-de-Classificacao-Haskell

Programa em Haskell que lê resultados de um campeonato de futebol, valida a entrada e mostra a tabela de classificação. Desenvolvido no Haskell Playground.

Links do Playground
Main.hs: https://play.haskell.org/saved/kereR8Gk
Testes.hs:

Arquivos
> Main.hs: o programa, dividido em Camada 1 (tipos), Camada 2 (classificação), Camada 3 (leitura e saída) e main.
> Testes.hs: os testes (é apenas o Main.hs mas com os testes no lugar do main).
> Decisoes.md: decisões de projeto e limitações.


# Como executar
1. Abra o link do Main.hs (ou do Testes.hs) acima.
2. Clique em Run.

Os dados do campeonato estão no próprio código (dadosCampeonato), porque o playground não tem entrada pelo teclado.
